Sobre o Projeto

O Pobre Flix é um sistema desenvolvido para pesquisar informações de filmes e séries utilizando a API OMDb.

O usuário pode realizar pesquisas pelo título de um filme ou série e visualizar informações detalhadas como:

  • Título
  • Ano
  • Gênero
  • Diretor
  • Atores
  • Duração
  • Idioma
  • País
  • Nota IMDb
  • Sinopse

Tecnologias Utilizadas

  • HTML5
  • CSS3
  • Bootstrap 5
  • JavaScript
  • API OMDb
  • LocalStorage
